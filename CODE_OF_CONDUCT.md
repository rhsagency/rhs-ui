# Code of conduct

RHS UI is a small open-source project run by a small company. We want it to be
a place where people can ask questions, propose changes and disagree about
code without being made to feel unwelcome.

## The short version

- Be respectful. Critique code and ideas, not people.
- Assume good faith. Most misunderstandings are just that.
- No harassment, discrimination, personal attacks or unwelcome sexual attention,
  in issues, pull requests, discussions or anywhere else the project meets.
- Keep discussions on topic and constructive.

## Enforcement

Maintainers may edit, remove or reject contributions and comments that do not
follow this code, and may block repeat offenders. Report problems to
**conduct@rhsagency.nl**; reports are handled confidentially by RHS Agency.

This document is adapted from the spirit of the Contributor Covenant, version
2.1, kept deliberately short.
